getibphysics — IB PHYSICS HL

START
1. Extract the entire ZIP to a folder. Do not open index.html from inside the ZIP preview.
2. Open index.html in a current desktop browser.
3. Keep index.html, app.js, styles.css, data, assets and vendor together.

All lessons, questions, formulae, fonts and booklet pages are included locally.
There is no sign-in, installation, build step, video, subscription or network dependency.
If your browser restricts local files, serve this folder with any ordinary static web server.

CONTENTS
- 24 study guides covering the first-assessment-2025 core and additional HL syllabus.
- Approximately 13,000 words of original notes, with key relationships, worked examples,
  common mistakes and revision checklists.
- 1,000 original multiple-choice practice questions: 44 for each A/B topic and 40 for
  each C/D/E topic. Includes conceptual questions, multi-step problems and numerical
  question families with varied data. These are practice items, not official IB questions.
- A Check answer button reveals the answer and explanation for each question.
- Topic, theme, content level, difficulty, keyword and progress filters; bookmarks.
- 288 vocabulary flashcards, 12 per topic, with review ratings and a browse view.
- 130 annotated equation groups from the supplied booklet; 40 additional relationships
  to recall or derive; all 18 booklet constants, SI prefixes and unit conversions.
- Original booklet PDF and grayscale page images preserving its mathematical layout.
- Four small interactive graphs in the relevant study guides.

PROGRESS
Read guides, checked answers, bookmarks and flashcard ratings are stored in this browser's
local storage. The site sends no progress data anywhere. Moving the folder, clearing browser
data, using private mode or switching browsers may change or erase the local progress record.
Use ? > Export progress for a backup. Import progress replaces the current local record.
Use ? > Reset all progress to start again; the site asks you to confirm the reset.

APPEARANCE
Use the header Light / Dark toggle. Your choice is saved in this browser.
Both modes preserve the full content, controls, mathematical notation and graphs.

KEYBOARD
Question bank: 1–4 selects an option, Enter checks from the focused option or page,
and N moves to the next question. Standard Tab / Enter controls also work.
Flashcards: Space reveals when the card or page has focus. Rate with the visible buttons.
Data booklet section tabs support arrow keys, Home and End.
Animations respect the browser's reduced-motion preference.

SOURCES
Coverage follows the supplied Physics guide (first assessment 2025) and school workbooks
(11 HL/SL 2025–26 and 12 HL 2026–27). Lessons, definitions, questions and annotations
are original revision materials. The supplied Oxford Physics 2023 volume is image-based;
its prose and questions have not been reproduced.

The included Physics data booklet, February 2023 version 1.0, is the user-supplied file.
Its original attribution and copyright notice remain in the PDF. The on-site annotations
are separate explanations. getibphysics is independent of the International Baccalaureate and
Oxford. Consult your teacher's course requirements alongside these revision materials.

KaTeX 0.16.22 supplies local mathematical typesetting under the MIT licence.
The licence is included at vendor/LICENSE-katex.txt.
Inter (latin, variable) supplies the typeface under the SIL Open Font License;
the licence is in vendor/fonts-ui/.

TECHNICAL
This is a static HTML / CSS / JavaScript site. Data are readable in data/*.js.
No package installation is needed. Any static host can serve this folder unchanged.
Browser QA covered desktop and 390 px mobile layouts on a local HTTP preview. Direct
file launch uses the same classic scripts and relative assets, without fetch or modules.
